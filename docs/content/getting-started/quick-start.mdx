# Quick Start

This guide walks you through the full MorphoCLIP pipeline: downloading data, extracting features, and training the model.

Every pipeline step is a `morphoclip` subcommand; run `uv run morphoclip --help` for the full list.
The dev loop (tests, lint, types) runs through [poe](https://poethepoet.natn.io/) instead:
`uv run poe check`.

## Command Reference

| Step                            | Command                                                              |
| ------------------------------- | -------------------------------------------------------------------- |
| Fetch dataset from S3           | `uv run morphoclip data fetch`                                        |
| Extract DINOv3 features         | `uv run morphoclip features extract`                                  |
| Download pre-extracted features | `uv run morphoclip features download`                                 |
| Pre-compute text embeddings     | `uv run morphoclip text precompute`                                   |
| Train model                     | `uv run morphoclip train --config configs/train/base.yaml`            |
| Evaluate model                  | `uv run morphoclip eval --checkpoint <path>`                          |
| Run inference                   | `uv run morphoclip infer --checkpoint <path>`                         |
| Run tests, lint and type checks | `uv run poe check`                                                    |

`uv run poe train` is shorthand for the training row, which is the one command with a default config.

## Training Pipeline

```bash
# 1. Download pre-extracted DINOv3 features from Hugging Face
uv run morphoclip features download

# 2. Pre-compute text embeddings (once)
uv run morphoclip text precompute

# 3. Train MorphoCLIP (default config configs/train/base.yaml)
uv run poe train

# 4. Evaluate a trained checkpoint
uv run morphoclip eval --checkpoint output/morphoclip_runs/default/checkpoints/best.pt

# 5. Run inference (top-k matching or embedding export)
uv run morphoclip infer --checkpoint output/morphoclip_runs/default/checkpoints/best.pt
uv run morphoclip infer --checkpoint output/morphoclip_runs/default/checkpoints/best.pt --mode embed

# 6. Export benchmark-layout profile CSVs
uv run morphoclip export-profiles --checkpoint output/morphoclip_runs/default/checkpoints/best.pt
```

## Training Configuration

The default config is at `configs/train/base.yaml`. Key options:

- `loss_type`: `"infonce"` (standard contrastive) or `"cwcl"` (soft-label contrastive)
- `aggregator`: how channels and sites are pooled into a well embedding:
  `"ccf-mean"` (default), `"meanpool-mean"`, `"ccf-attn"`, or `"wellformer"`
- `use_cwa`: `true` to enable Cross-Well Alignment, a batch correction that subtracts
  precomputed per-plate offsets relative to each plate's replicate plates (disabled by default)
- Outputs saved to `output/morphoclip_runs/<run_name>/`

Alternative configs:

- `configs/train/mean_pool.yaml`: mean pooling instead of CrossChannelFormer (`aggregator: meanpool-mean`)
- `configs/train/ddp.yaml`: multi-GPU distributed training

## Multi-GPU Training

Replace `poe train` with a direct `torchrun` invocation and add `--distributed`:

```bash
# MorphoCLIP on 4 GPUs
uv run torchrun --nproc_per_node=4 -m morphoclip.cli train --config configs/train/base.yaml --distributed

# CellCLIP on 4 GPUs
uv run torchrun --nproc_per_node=4 -m morphoclip.cli cellclip train --config configs/cellclip/official_baseline.yaml --distributed
```

The batch size in the config is **per-GPU**, so effective batch = `batch_size x num_gpus`.

## TensorBoard Monitoring

Training logs metrics to TensorBoard automatically (tensorboard ships with the project deps):

```bash
uv run poe tensorboard                                          # MorphoCLIP (output/morphoclip_runs)
uv run tensorboard --logdir output/train_runs/ --port 6006      # CellCLIP
```

If running on a remote machine, forward the port over SSH: `ssh -L 6006:localhost:6006 user@remote-host`
